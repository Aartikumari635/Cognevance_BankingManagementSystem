# Banking Management System

## Project Overview
A Java-based Banking Management System developed using NetBeans and MySQL.

## Technologies Used
- Java
- MySQL
- JDBC
- NetBeans IDE

## Features
- User Login
- Account Management
- Fund Transfer
- Deposit and Withdrawal
- Transaction History

## How to Run
1. Open the project in NetBeans.
2. Configure the MySQL database connection.
3. Create the required database and tables.
4. Run the application from NetBeans.
